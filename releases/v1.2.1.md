Codex 像素办公室将真实 Codex 会话变成像素风格办公室中的虚拟员工，直观展示工作状态、任务活动和主会话与子代理的协作关系。

## 本次更新

相较于已有的 v1.1.0 标签：

- 新增“叫人来加班”：从办公室界面启动新的 Codex 会话。
- 新增聊天中断控制：在界面中停止当前执行。
- 优化会话轮询及聊天超时处理。
- 修复 Windows `.cmd` 启动器的引号处理，恢复带空格和 `&` 路径中的 Codex 启动。
- 固定前端文件的 MIME 类型，避免 Windows 系统设置导致 JavaScript 无法加载。
- 修正 Windows 短路径与完整路径的测试比较。
- 统一 README 与版本声明，并增加自动测试、打包和 Release 发布流程。

同时包含 Linux GTK 桌面、Windows WebView2 桌面和浏览器运行模式，以及像素员工状态展示、模型选择和会话续聊。

## 下载与运行

本次提供源码发行包，不包含独立 EXE 或系统安装包。

- Windows：下载 `codex-pixel-office-v1.2.1-source.zip`，解压后按 README 安装依赖，使用 `run-windows.cmd` 启动桌面窗口，或 `start-windows.cmd` 启动浏览器模式。
- Linux：下载 `codex-pixel-office-v1.2.1-source.tar.gz`，解压后使用 `./run-desktop.sh` 启动桌面窗口，或 `./start.sh` 启动浏览器模式。
- `SHA256SUMS.txt` 提供两个源码包的 SHA-256 校验值。

需要 Python 3.11+；浏览器模式仅使用 Python 标准库。Linux 桌面需要 GTK4 / WebKitGTK 6 / PyGObject；Windows 桌面需要 pywebview 和 WebView2。聊天功能需要本机已安装并登录 Codex CLI。

## 验证与兼容性

发布流程要求 Linux、Windows 的 Python 3.11 / 3.13 自动化测试通过，并检查 JavaScript 语法和 Windows 启动脚本。自动化验证不替代真实桌面环境中的人工体验测试。

项目依赖 Codex 本地状态格式，上游格式变化可能需要适配。默认只监听本机回环地址。安装菜单快捷方式后请保留源码目录位置。
